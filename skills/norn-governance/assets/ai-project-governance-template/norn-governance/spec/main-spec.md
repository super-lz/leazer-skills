# 主实现规格

- 决策状态：**Proposed**
- 当前交付范围：**Unconfirmed**
- 实现状态：**Not started**

本文件是项目的语义权威。开始产品实现前，必须完成并确认本规格。

## 产品目的与用户结果

描述真实用户、问题、持久目的和可观察结果。

## 当前已接受范围

定义当前已获授权实施的最小完整交付边界。

## 持久不变量

记录在语言、框架、代码组织、宿主和实现机制变化后仍必须成立的规则。

## 核心流程与状态

描述端到端用户流程、有意义的状态与转换、副作用和所有权边界。

## 契约与失败

定义稳定接口、兼容预期、校验、失败、取消、恢复、安全和隐私行为。

## 验收条件

说明判定当前范围完成所需的可观察证据。

## 延后范围与非目标

列出明确未获授权的想法。延后项必须先经过已确认的主规格变更，才能实施或搭建脚手架。

## 未决决策

只记录会实质阻塞或改变当前已接受范围的未决决策。
